# ZTRX PR 69 texture descriptor on RTX 5080

I tested clean ZTRX main `90b529f878a470fec9bf07b7be316bc769a12232` and PR head `0cad4faaaebe1b504d464aa9c7bcb269432cb53e` using Windows 11 Pro 25H2 build 26200.9974, RTX 5080 16 GB with driver 617.14, and an MSVC Rust 1.98.1 diagnostic build. [ZTRX PR 69](https://github.com/Zettrox/ztrx/pull/69)

All three `texture_size_word` tests passed on the candidate. The D3D12 fixture read the expected packed dimensions and texel from the selected 9 × 6 view with no adapter skips. The fixture also runs on WARP. The two other tests verified that the single-dword lowering matches the full descriptor reload and that the translator refuses a read from an unrelated entry.

I passed two previously identified pixel programs through `translate --jobs 1 --validate --pipelines --list` on both revisions. The hash and reported offset matched the earlier RTX 5090 report. Both programs reached I/O analysis but emitted no DXIL on either revision. [RTX 5090 report](https://github.com/Zettrox/ztrx/pull/69#issuecomment-7156985694)

| Program | Translator-reported offset | ZTRX main | ZTRX PR 69 |
| --- | ---: | --- | --- |
| `6b6db9f1a526daeb` | `0x49dc` | Descriptor read only as data | Same refusal |
| `7d0f14ce44746d7e` | `0x5204` | Descriptor read only as data | Same refusal |

PR 69 requires a single size-word load paired with a proven 2D image use. The separate NVIDIA fork PR 203 experiment used a broader lowering for full descriptor loads with no proven image use, and both programs emitted and created pipelines in that experiment. That earlier test is a useful comparison for the two refusals. This ZTRX check ran the synthetic fixtures and offline translation. [Earlier PR 203 comparison](https://github.com/iGoldenNinja/victory-fork/blob/b2ab0beee1d7a6aade0d9184c6647afc5868674e/docs/ssd-pr203-descriptors-5080.md)

## Retest on `811d2ca`

After the author added support for full eight-dword pixel descriptor loads used only for size, I reran the same inputs and translation command on clean `811d2ca654a9f3b0f4947fd79a9ac185691cdf03`. Both programs emitted DXIL, validated and created D3D12 test pipelines on the RTX 5080. [Author's retest request](https://github.com/Zettrox/ztrx/pull/69#issuecomment-7157733893)

| Program | DXIL emitted | Validated | D3D12 pipeline created |
| --- | --- | --- | --- |
| `6b6db9f1a526daeb` | Yes | Yes | Yes |
| `7d0f14ce44746d7e` | Yes | Yes | Yes |

All five `descriptor_tests` passed, including the two new cases for a descriptor used only for dimensions and the negative metadata and size-read cases. The D3D12 readback fixture completed on hardware and WARP with no skips. This retest establishes offline translation, validation and pipeline creation for these programs. Gameplay rendering remains unverified.
