# ZTRX PR 94 readback on RTX 5080 and WARP

I tested ZTRX PR 94 at `c8020f66dec029c88bfc04e749d62b129fc76768` on Windows 11 Pro 25H2 build 26200.9974, with an RTX 5080 16 GB, driver 617.14, Ryzen 9 5900X and 32 GB RAM. The diagnostics-profile build used Rust 1.98.1. [ZTRX PR 94](https://github.com/Zettrox/ztrx/pull/94)

| Test | Result |
| --- | --- |
| Portable coalescing tests | 3 passed |
| D3D12 WARP copy fixture | 4 copy commands for 6 pieces, all 40 destination bytes verified after the fence |
| D3D12 RTX 5080 copy fixture | 4 copy commands for 6 pieces, all 40 destination bytes verified after the fence |

The portable tests cover exact adjacency, gaps, overlaps, source-resource changes and offset overflow. The native fixture copies from two source resources and checks the copied ranges and untouched sentinel bytes. My local changes were confined to test code. They make device creation mandatory for this fixture, select the RTX 5080 for the hardware run, and print the successful command and byte counts.

The last verified stage was synthetic D3D12 readback after fence completion. Title copy counts and frame-time effects remain unmeasured.
