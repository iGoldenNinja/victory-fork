# NVIDIA PR 774 descriptor mirroring on the RTX 5080

I tested PR 774 at `0941c0dbd67f9fe2e6f4bd650079dc9f94a3f777` against its base `a26859fc5f512e0db0d7522d3da821c038378ab7`. The PR batches the descriptor fingerprint lock once per changed page and replaces the per-record BLAKE3 hash. Its reported RTX 3050 measurements came from a different system and a Series S profile. [PR and original measurements](https://github.com/fxceless/victory-fork/pull/774)

Both local builds used the Series X profile, default second-stage relay and DRED. Hardware was an RTX 5080 16 GB, NVIDIA driver 617.14, Ryzen 9 5900X and 32 GB RAM, running Windows 11 Pro 25H2 build 26200.9974. Both were MSVC Rust 1.98.1 diagnostics builds with identical local archive reads and replay input support. The title was offered a 3840 × 2160 display mode. The candidate used a fresh shader translation cache and reused the existing mapped image cache and host pipeline library. The library had grown between runs.

Both builds reached controllable prison gameplay. The five-minute route used three timed camera pans and five forward or backward movements. The first pan matched within 21 ms after player selection. In the corresponding post-retreat view, both rendered the walls, ceiling, lights and bunks. The character's pose differed and the stepped shoulder artifact was visible in both.

The descriptor counter improved by 36.5%, with 6.7% fewer mirrored records per frame, across 257 base and 261 candidate log samples. Average display rate improved by 4.7% in this pair, while P99 and the worst hitch increased. The host counters can overlap in elapsed time. All five movement inputs were logged, with an offset difference of at most 14 ms from the first pan. Both startup logs reported zero shader-cache hits. Both builds logged the same seven distinct `E_INVALIDARG` pipeline refusals. Title-process PCM was present, DRED logged no device removal, and both runs ended deliberately after capture. These results cover one replay per build. [Base replay](https://github.com/iGoldenNinja/victory-fork/blob/53c154d9ba61c701753a95b70ea2125c252ab62f/docs/ssd-a26859f-5080.md)
